# Machine Learning-Based Adaptive RF–FSO Switching for Satellite Communication
## 1. Project Overview
This project investigates adaptive switching between Radio Frequency (RF) and Free-Space Optical (FSO) communication links for satellite-to-ground communication.
The objective is to evaluate whether selecting a suitable communication link based on estimated link conditions can reduce the theoretical Bit Error Rate (BER).
The project combines BPSK link simulations, RF and FSO link analysis, rule-based switching, and a Random Forest classifier.
## 2. Objectives
- Simulate a baseline BPSK communication system.
- Evaluate RF link performance under different SNR conditions.
- Study FSO link performance under different attenuation conditions.
- Develop a hybrid RF–FSO link-selection strategy.
- Generate synthetic scenarios for machine-learning evaluation.
- Compare RF-only, FSO-only, rule-based, and Random Forest strategies.

## 5. Python Workflow
The Python scripts are numbered to represent the intended workflow:
1. Establish the BPSK baseline.
2. Evaluate the RF link.
3. Evaluate the FSO link.
4. Analyse hybrid RF–FSO selection.
5. Evaluate threshold-based switching.
6. Generate a synthetic dataset.
7. Train the Random Forest model.
8. Evaluate the model.
9. Compare strategies.
10–12. Evaluate matched scenarios and machine-learning predictions.
13–15. Generate final strategy comparisons and summary results.
Run scripts from the project root using commands such as:
```powershell
python .\python\step6_generate_dataset.py
```
Some scripts depend on files generated by earlier steps. Review each script before rerunning it because it may overwrite existing outputs.
## 6. Reported Results
The current strategy comparison reports the following mean theoretical BER values:
| Strategy | Mean theoretical BER |
|---|---:|
| RF-only | 0.00852917 |
| FSO-only | 0.13460847 |
| Rule-based switching | 0.00548393 |
| Random Forest | 0.00561874 |
Relative to RF-only, the reported mean theoretical BER reduction is approximately:
- Rule-based switching: 35.70%
- Random Forest: 34.12%
These figures describe the current synthetic simulation dataset and its assumptions.
## 7. Machine-Learning Evaluation
The matched-scenario Random Forest evaluation reported 97.41% accuracy across 10,000 synthetic scenarios.
This evaluation used the full matched-scenario dataset rather than an independent held-out test set. The scenario labels were generated using a rule-based selection criterion. Therefore, the reported accuracy should not be interpreted as independent generalisation performance or real-world satellite-link accuracy.
## 8. Limitations
- The results are based on simulated or synthetic link conditions.
- The BER comparison uses theoretical BER estimates derived from link SNR values.
- The current results do not establish real-world end-to-end satellite communication performance.
- The FSO model uses simplified attenuation assumptions.
- Independent test data and more realistic channel models are needed for stronger validation.
- The current implementation should not be described as a validated operational satellite system.
## 9. Future Work
- Validate the model using a separate held-out test dataset.
- Improve RF and FSO channel models.
- Investigate atmospheric turbulence, pointing errors, and changing channel conditions.
- Extend the simulations to include realistic satellite-to-ground parameters.
- Validate the switching strategy with a consistent end-to-end simulation framework.
